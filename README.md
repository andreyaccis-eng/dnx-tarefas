# DNX Digital Tarefas

Quadro Kanban da equipe DNX Digital. Site estático (GitHub Pages) com dados, login e anexos no Supabase.

- `index.html`: o app inteiro.
- `supabase/schema.sql`: tabelas, regras de acesso e gestores (já aplicado no projeto dnx-tarefas).

A primeira conta criada vira administrador. As demais contas precisam ser ligadas a um gestor na tela Gestores.
